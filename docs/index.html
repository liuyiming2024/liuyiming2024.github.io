使用手册

按项目分栏目。账号与权限是全站共用的，单独一栏在最上面 —— 在一个地方登录、一个地方配权限，各项目通用。

账号与权限 全站共用 site
登录
全站唯一的登录入口。任何项目需要登录都会跳转到这里。
账号设置
头像、昵称、简介、修改密码。审核注册申请也在这里。
权限配置
跨项目权限点，按项目分组。仅站长与管理员可见。
站点设置
站点名、注册开关、整站保护密码。仅站长可见。
聊天室 Chat chat
新手入门
注册、进群、发消息、@ 提醒。第一次用先看这个。
Markdown 与公式
支持的语法、LaTeX 公式写法、代码块高亮。
权限与命令
房间内权限点说明与斜杠命令。
管理员手册
审核、封禁、置顶、公告、导出。
客户端下载
桌面版安装包与更新说明。
部署与数据
数据存在哪、怎么备份、离线能用吗。
⚠ 聊天室的房间内权限（能不能删这条消息）与跨项目权限 （能不能用云盘）是同一套 acl_can，只是作用域不同。 房间内的在这栏，跨项目的在「账号与权限」。

打开编辑器
浏览器内的代码编辑器，自研 pylite / cpplite。
